# Limitaciones conocidas actuales

1. No se ha ejecutado Docker en el entorno de remediación.
2. Las integraciones externas requieren credenciales y validación real.
3. FlowWink se utiliza como componente visual/configurable; el núcleo transaccional es Bridge API.
4. La facturación definitiva permanece fuera del MVP de Ofideep.
5. Los costes de IA no se calculan hasta configurar un catálogo de precios actualizado.
6. El buscador determinista está optimizado para el piloto inicial de 100–300 productos; catálogos grandes requerirán índice de búsqueda dedicado.
7. La sincronización enriquecida de PrestaShop realiza más llamadas para obtener características y combinaciones; debe programarse y monitorizarse.
8. El portal fue validado por TypeScript, pero el build Docker y la revisión visual siguen pendientes.
9. Los scripts PowerShell no se ejecutaron en este entorno.
10. La seguridad no está certificada externamente.
