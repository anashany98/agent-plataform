# Platform User Guide

## Navigating the Admin Control Portal
Access `http://localhost:3005` in your browser.

1. **Dashboard:** Overview of service health, total executions, token consumption, and pending approvals.
2. **Agentes IA:** View registered agents, system prompts, and LLM model profiles (`cheap`, `standard`, `advanced`, `critical`).
3. **Aprobaciones:** Review pending human approval requests for invoice drafts, quotes, and SEO updates. Click **Aprobar** or **Rechazar**.
4. **Productos & Stock:** Inspect products catalogue, prices, stock levels, and pricelists.
5. **Costes & Tokens:** Track token consumption, latency, and estimated USD costs by execution.
